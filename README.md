# Tech Notes

AWS、Azure、Windows、Linux などの技術メモを残すためのリポジトリです。

## フォルダ

```text
aws/       AWS関連
azure/     Azure関連
windows/   Windows / RDP / AD など
linux/     Linux / RHEL / systemd など
templates/ メモ用テンプレート
```

## メモの方針

- 完璧な記事にしない
- 結論、前提、確認コマンド、参考URLを残す
- 事実関係の説明は、原則として公式ドキュメントの引用を根拠にする
- 公開前提の文章にしなくてよい
